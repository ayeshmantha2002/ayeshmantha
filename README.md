## ✨ Next-Level Features

1. **Seamless Borderless Embedding**:
   - Zero-gap, edge-to-edge native look with zero parent scrollbars.
   - Dynamic viewport sizing (`100dvh`) with native mobile Safari / Chrome viewport adjustments.
   - Comprehensive cross-origin permissions (`camera`, `clipboard`, `fullscreen`, `web-share`, etc.).

2. **Cyber Glassmorphic HUD (Heads-Up Display)**:
   - Floating glassmorphism island at the bottom right.
   - Live Host Status Indicator (`dev.pasindumsoyza.lk • Connected`).
   - Quick Standalone Launcher (`Open in New Tab`).
   - One-click Iframe Hard Refresh.
   - Fullscreen API Mode toggle.
   - Collapsible dock to maintain an uncluttered portfolio view.

3. **Interactive Device Viewport Simulator**:
   - **🖥️ Desktop Mode**: 100% full-screen immersive view.
   - **💻 Tablet Mode**: Realistic 840px tablet bezel frame with rounded corners and ambient studio drop shadow.
   - **📱 Mobile Mode**: 390px iPhone/Pixel smartphone mockup with dynamic island notch and home indicator bar.

4. **Sharing & Dynamic QR Code**:
   - Integrated client-side QR Code modal for instant mobile scanning.
   - One-click link copy with animated toast notifications.
   - Native Web Share API trigger for mobile visitors.
   - Direct social contact shortcuts (LinkedIn, WhatsApp, GitHub, Email).

5. **Cyber Preloader**:
   - Animated microchip SVG with dual-orbiting glow rings.
   - Real-time network handshake progress bar and status log messages.
   - Smooth 0.5s fade-out once the target host responds.

6. **Host Delay & Fallback Engine**:
   - Automatic fail-safe overlay if the primary host is undergoing maintenance or delayed.
   - Provides direct contact links and reconnection retry.

7. **SEO, OpenGraph & Social Cards**:
   - Rich link preview cards on WhatsApp, LinkedIn, Facebook, and Twitter.
   - JSON-LD Structured Data for search engines.

8. **PWA (Progressive Web App)**:
   - Installable on Android, iOS, and Desktop Chrome/Edge with custom cyber microchip icon.

## ⚙️ How to Deploy on GitHub Pages

1. Commit and push the repository:
   ```bash
   git add .
   git commit -m "Deploy Next-Level Portfolio Wrapper"
   git push origin main
   ```
2. In your GitHub repository (`ayeshmantha2002/ayeshmantha`):
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select the branch: `main` / `/(root)` and click **Save**.
3. Your site will be live at:
   - **`https://ayeshmantha2002.github.io/ayeshmantha/`**
   *(Or `https://ayeshmantha2002.github.io/` if you name your repository `ayeshmantha2002.github.io`)*.
